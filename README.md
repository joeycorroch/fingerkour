# FINGERKOUR

**Backseat finger parkour** — a retro pixel-art runner inspired by kids "running" their fingers along everything outside the car window.

▶ **Play:** https://joeycorroch.github.io/fingerkour/

- 7 Road Trip levels + Endless mode: Old Town, Skyline Heights, Chinatown, Greenway Park, Sunset Point, Saltwater Bay and Midnight Motorway
- Flips, spins, reward gestures, power-ups (Magnet, Slow-Mo, Rainbow, Super Jump and the rare Wind Rider)
- Plays on desktop (keyboard), phones/tablets (touch arcade controls) and game controllers

**Controls:** Space/↑ jump · → run · ← walk · I/O/P tricks · Esc pause. Controller: A jump, B/X/Y tricks, bumpers/stick run & walk, Start pause.

Music: "80s Synthwave" by AtlasAudio, "Synthwave" by Monume and "Synthwave" by JonasBlakewood (Pixabay).
